#( EasyChat
A self-hostable AI interface that is easy to use. The [TinyMinstral-248M](https://huggingface.co/Locutusque/TinyMistral-248Mhttps://huggingface.co/Locutusque/TinyMistral-248M) AI model is the default. This cannot be hosted locally because of modules cannot be loaded locally, so you may want to install `npm` and install `live-server` with `npm install live-server` and go to the `src` directory and type `live-server .` to run this. Otherwise, you can self host this or visit the GitHub page, which has it ready to go. The module used for interacting with the model is [llm.js](https://rahuldshetty.github.io/llm.js/#/). Proudly written in Kate.
